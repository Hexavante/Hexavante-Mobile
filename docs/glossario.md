# Glossário — Hexavante Mobile

Documento de referência dos termos usados no código.

---

| Termo | Significado |
|-------|-------------|
| Rota | Arquivo em `src/app/` (expo-router gera a navegação) |
| Pilha | Navegação empilhada (detalhes por cima das abas) |
| Secure store | Cofre do SO para o token (`expo-secure-store`) |
| Deep-link | URL com `scheme` que reabre o app (retorno do OAuth) |
| EAS | Serviço de build/submit (APK/AAB/IPA) |
| Expo Go | App de desenvolvimento para testar sem build nativo |
