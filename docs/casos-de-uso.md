# Casos de uso — Hexavante Mobile

Documento de referência dos fluxos **implementados**.

---

## UC-01 — Primeiro acesso

1. Instala/abre via Expo Go → login ou cadastro.
2. OAuth abre o navegador do sistema e retorna por deep-link.
3. Cai no catálogo com a sessão salva.

## UC-02 — Estudar no ônibus

1. Abre um curso → assiste em fullscreen → progresso sincroniza.
2. Sem rede: aviso + fila para sincronizar depois.

## UC-03 — Fazer simulado

1. Lista com filtros → detalhe → prova → resultado e histórico.

## UC-04 — Ver conquistas

1. Perfil → grade de conquistas, certificados e cosméticos.
